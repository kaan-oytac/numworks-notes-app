# Notes guide

Write notes as Python scripts in the **NumWorks Workshop**, name them `note_xxx.py`, sync, and they appear here. Markdown and LaTeX maths both render.

## Text

Normal, **bold**, *italic* and `code`. Lists:

- a bullet
- another one
  - nested
1. first
2. second

> A quote block, for definitions or reminders.

---

## Maths

Inline maths with dollars: the roots are $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$ and $e^{i\pi}+1=0$.

Display maths with double dollars:

$$\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}$$

$$\int_0^1 x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac{1}{3}$$

$$\lim_{x \to 0} \frac{\sin x}{x} = 1, \quad \sqrt[3]{27} = 3, \quad |\vec{v}| = \sqrt{v_x^2 + v_y^2}$$

Greek: $\alpha, \beta, \gamma, \delta, \theta, \lambda, \mu, \pi, \sigma, \omega, \Delta, \Sigma, \Omega$. Relations: $a \leq b$, $a \geq b$, $a \neq b$, $a \approx b$, $x \to \infty$.

## Tables

| Test | Converges when |
|:-----|:--------------:|
| Geometric | $|r| < 1$ |
| p-series | $p > 1$ |
| Ratio | $\rho < 1$ |

Start each row with `|`. The row above `|---|` is the header; colons set the alignment.

## Keys

- **Up/Down**: scroll one line. **Left/Right**: previous/next page.
- **OK**: contents, jump to any heading.
- Type any letter or digit (Alpha + key) to **search**. EXE or Down: next match, Up: previous, Back: close.
- **Toolbox**: switch the text size. **Back**: return to the list (the position is remembered).
