=== Quadratics
# Quadratics
For $ax^2 + bx + c = 0$:
$$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
- Discriminant $\Delta = b^2 - 4ac$: two roots if $\Delta > 0$, one if $\Delta = 0$, none (real) if $\Delta < 0$.
- Vertex at $x = -\frac{b}{2a}$.
- Sum of roots $-\frac{b}{a}$, product $\frac{c}{a}$.

=== Trig identities
# Trig identities
$$\sin^2\theta + \cos^2\theta = 1 \qquad \tan\theta = \frac{\sin\theta}{\cos\theta}$$
$$\sin(a \pm b) = \sin a \cos b \pm \cos a \sin b$$
$$\cos(a \pm b) = \cos a \cos b \mp \sin a \sin b$$
$$\sin 2\theta = 2\sin\theta\cos\theta \qquad \cos 2\theta = 1 - 2\sin^2\theta$$
> Degrees to radians: multiply by $\frac{\pi}{180}$.

=== Calculus
# Calculus
## Derivatives
- $(x^n)' = n x^{n-1}$, $(e^x)' = e^x$, $(\ln x)' = \frac{1}{x}$
- Product: $(uv)' = u'v + uv'$. Quotient: $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$
- Chain: $(f(g(x)))' = f'(g(x))\, g'(x)$
## Integrals
$$\int x^n\,dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$$
$$\int_a^b f(x)\,dx = F(b) - F(a)$$
